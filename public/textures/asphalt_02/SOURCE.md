# Asphalt 02 texture set

- **Source:** [Poly Haven — Asphalt 02](https://polyhaven.com/a/asphalt_02)
- **License:** CC0 1.0 Universal (public domain). No attribution required.
- **Resolution:** 2K JPG
- **Maps:**
  - `diff.jpg` — albedo / base color (sRGB)
  - `nor.jpg` — OpenGL normal map (linear)
  - `arm.jpg` — packed AO (R) / Roughness (G) / Metalness (B); used as the roughness map

Used by `src/domains/viewer/components/RoadMesh.tsx` to render realistic asphalt roads.
